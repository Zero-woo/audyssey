## 해석할 때 주의

- **κ 1.00의 뜻:** 이것은 "규칙을 받은 모델끼리 답이 같다"는 뜻입니다. 사람 사이의 모호함을 잰 값이 아닙니다.
  - 생성과 풀이 모두 같은 명시적 규칙을 받았기 때문에, 규칙 밖의 모호한 표현은 적게 들어갔을 수 있습니다.
  - 이를 보완하려고 사람 검수용 표본 30개(`review_sample.md`)를 따로 뽑았습니다.
- **라우터는 이 규칙을 받지 않습니다.** 라우터가 보는 것은 `descriptions.json`뿐이므로, 평가는 "짧은 설명만 보고 같은 판단을 하는가"를 재게 됩니다.
- **Gemini의 이중 역할:** Gemini는 평가 대상이면서 생성자이기도 합니다. 결과는 출처(`c`/`x`/`g`)별로 나눠 보고합니다.
  - test 분할의 출처 구성은 c 26, x 29, g 15입니다.
