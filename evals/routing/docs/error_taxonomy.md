## 명령 경계 문제 (사람이 정할 것)

- **지원하지 않는 편집 기능**(자르기, 배속, 화면 필터)은 지금 정답이 `none`입니다. 생성 가이드 규칙 6과 spec 4.1의 "자막 넣어줘(지원 안 함) → none"을 따른 것입니다.
- Gemini는 이런 요청에 `clarify(unsupported)`, 즉 "그 기능은 지원하지 않습니다"라고 답합니다. 사용자 경험으로 보면 이쪽이 더 친절합니다.
- 선택지는 두 가지입니다.
  - **(a)** `none`을 유지하고, 설명에 "편집 명령 목록에 없는 기능은 none"을 분명히 적는다.
  - **(b)** 두 답을 모두 허용한다.
- Gemini의 dev 실패 3개 중 2개가 이 경계에서 나왔습니다.

## 다음에 고칠 것 (설명 수정 후보, train 실패로 확인 후)

1. **`set_pitch` 예시:** 예시 값이 결과로 새어 나가지 않게 바꾼다. 예: 현재 0일 때 "반음 내려" → −1. 예시 개수와 값을 섞는 방법도 있다.
2. **`generate`, `reseparate`:** 할 수 없는 경우(대사, 생성 stem, 무음 영상)를 `when`의 첫 문장으로 올린다.
3. **residual:** `keep`, `drop`, `set_gain` 설명에 "'나머지 소리', '남은 소리', '배경 잡음(분리되지 않은 것)'은 residual"을 넣는다.
4. **`keep`, `drop`:** "음소거", "음소거 해제"를 넣는다.
5. **`add_source`와 `generate` 구분:** "새로운 소리를 추가"하는 것과 "기존 소스를 바꿈"을 대조해 적는다.
